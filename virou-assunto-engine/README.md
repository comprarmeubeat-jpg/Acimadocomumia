# Virou Assunto Reel Engine

Engine experimental para produzir Reels jornalísticos do **Virou Assunto 24h** sem depender de editores pagos.

## Fase 1 — voz
O primeiro teste compara as três vozes nativas de português brasileiro do Kokoro-82M:

- `pm_alex`
- `pm_santa`
- `pf_dora`

O workflow gera WAV 24 kHz, normaliza o pico e publica um artefato com as três amostras e um relatório técnico.
