Como funciona?

1. Cadastre apenas seus dados reais na aba Perfil.

2. Tire um print da pergunta ou copie o texto.

3. Use a análise local ou ative a IA na aba IA para interpretar melhor a pergunta.

4. Confira e escolha a resposta na pesquisa, por conta própria.

INTELIGÊNCIA ARTIFICIAL

Conectar Gemini

Para entender imagens diretamente e perguntas mais complexas, use sua própria chave da API Gemini. Há uma modalidade gratuita com limites definidos pelo Google.

Criar chave gratuita no Google AI Studio ↗

A chave fica somente na memória da aba enquanto ela estiver aberta. Não é salva em arquivo, navegador ou servidor nosso.

Ao usar a IA, o texto e/ou print serão enviados diretamente à API do Google. Se ativar a opção acima, seu perfil e memórias também serão enviados. A modalidade gratuita pode usar dados para melhoria dos produtos, conforme as políticas do Google. Não envie documentos, senhas ou dados de terceiros.

Uso gratuito e instalação

Sem chave, o leitor de texto do print e a memória local continuam disponíveis. O primeiro uso do reconhecimento de imagem precisa de internet.

No iPhone, depois de publicar o site em HTTPS, abra-o no Safari, toque em Compartilhar e selecione Adicionar à Tela de Início.

A chave da API usada diretamente no navegador pode ser visível para quem acessar o aparelho, extensões ou scripts maliciosos. Para uso público com chave fixa, é necessário um backend que mantenha a chave secreta. Não use uma chave de conta faturável sem controles de gastos.
